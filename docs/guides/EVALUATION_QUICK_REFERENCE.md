## Key Concepts

### Skill Sources

**Agent-Generated Skills**
- Created via `keel skill generate`
- AI-powered using Claude/Gemini/GPT-4
- Follows OpenSkill format
- Auto-validated on creation
- Example: `pr-reviewer` skill generated by AI

**User-Generated Skills**
- Installed via `keel skill install`
- From GitHub repositories
- May need manual validation
- Example: `mcp-builder` from anthropics/skills

### Evaluation Types

**Skill Validation**
- Checks structure and completeness
- Validates YAML frontmatter
- Verifies required sections
- Assesses documentation quality
- Command: `keel eval validate skill`

**Skill Impact Evaluation**
- Measures how skill improves agent performance
- Compares baseline vs with-skill metrics
- Calculates effectiveness score
- Generates quality score
- Command: `keel eval run skill`

**Agent Evaluation** (Planned)
- Measures overall agent performance
- Tests with multiple skills
- Identifies best skill combinations
- Command: `keel eval run agent` (Phase 3)

### Key Metrics

**Quantitative** (Numeric)
- Accuracy: 0-1 (higher is better)
- F1 Score: 0-1 (higher is better)
- BLEU Score: 0-1 (higher is better)
- Latency: milliseconds (lower is better)
- Token Usage: count (lower is better)
- Cost: USD (lower is better)

**Qualitative** (1-5 Scale, LLM-Judged)
- Helpfulness: How well does it solve the problem?
- Clarity: Is the output clear and understandable?
- Relevance: Is the output relevant to the input?
- Safety: Does it avoid harmful outputs?
- Completeness: Does it fully address the request?

**Boolean** (Yes/No)
- Contains Hallucination: Does it make up facts?
- Is Complete: Does it have all required sections?
- Meets Requirements: Does it pass validation?

### Quality Score

**Calculation**:
- Aggregate all metrics
- Normalize to 0-1 range
- Apply weights
- Scale to 0-100

**Certification Levels**:
- **CERTIFIED**: Score ≥ 80 (Ready for production)
- **CONDITIONAL**: Score 60-79 (Use with caution)
- **NEEDS_IMPROVEMENT**: Score < 60 (Not recommended)
- **DEPRECATED**: Older version (Use newer version)

## Current CLI Commands

### Dataset Management

```bash
# Create a new evaluation dataset
keel eval dataset create <name> --description "..." --tags "tag1,tag2"

# List all datasets
keel eval dataset list

# Show dataset details
keel eval dataset show <dataset-id>

# Delete a dataset
keel eval dataset delete <dataset-id>
```

### Skill Validation

```bash
# Validate a skill file
keel eval validate skill <path-to-SKILL.md> --output console

# Validate and output JSON
keel eval validate skill <path-to-SKILL.md> --output json
```

### Skill Evaluation

```bash
# Run skill impact evaluation
keel eval run skill \
  --agent <agent-name> \
  --skill <skill-name> \
  --dataset <dataset-id> \
  --metrics "accuracy,helpfulness,latency_ms" \
  --judge "anthropic" \
  --parallel 1 \
  --save
```

### Metrics

```bash
# List all available metrics
keel eval metrics list
```

### Reports

```bash
# List evaluation reports
keel eval report list
```

## Planned Commands (By Phase)

### Phase 2: Unified Skill Evaluation

```bash
# Evaluate all installed skills
keel eval run all-skills \
  --dataset <dataset-id> \
  --agent <agent-name> \
  --parallel 4 \
  --judge "anthropic"
```

### Phase 3: Agent Evaluation

```bash
# Evaluate agent performance
keel eval run agent \
  --agent <agent-name> \
  --dataset <dataset-id> \
  --skills "skill1,skill2,skill3" \
  --judge "anthropic"

# Show agent evaluation report
keel eval report agent <agent-name>
```

### Phase 4: Comparison

```bash
# Compare multiple skills
keel eval compare skills \
  --skills "skill1,skill2,skill3" \
  --dataset <dataset-id> \
  --agent <agent-name> \
  --metrics "accuracy,helpfulness"

# Compare multiple agents
keel eval compare agents \
  --agents "agent1,agent2,agent3" \
  --dataset <dataset-id> \
  --skill <skill-name>

# Show analytics and trends
keel eval analytics \
  --skill <skill-name> \
  --period "30d" \
  --metrics "accuracy,helpfulness"
```

### Phase 5: Certification

```bash
# Certify a skill
keel eval certify skill \
  --skill <skill-name> \
  --level "CERTIFIED" \
  --reason "Meets all quality requirements"

# Show certification status
keel eval show certification <skill-name>

# List certified skills
keel eval list certified-skills
```

### Phase 6: Reporting

```bash
# Show evaluation trends
keel eval report trends \
  --skill <skill-name> \
  --period "90d"

# Generate summary report
keel eval report summary \
  --skills "all" \
  --format "json|csv|pdf"

# Export evaluation data
keel eval export \
  --skill <skill-name> \
  --format "json|csv" \
  --output <file-path>
```

## Data Models

### SkillEvaluationRecord

```python
@dataclass
class SkillEvaluationRecord:
    skill_id: str                           # e.g., "pr-reviewer"
    skill_source: str                       # "agent-generated" | "user-generated"
    evaluation_id: str                      # e.g., "eval-abc123"
    agent_name: str                         # e.g., "support-agent"
    dataset_id: str                         # e.g., "qa-dataset"
    timestamp: datetime                     # When evaluation ran
    
    # Metrics
    metrics: Dict[str, float]               # All calculated metrics
    quality_score: int                      # 0-100
    certification: str                      # CERTIFIED | CONDITIONAL | NEEDS_IMPROVEMENT
    
    # Results
    baseline_metrics: Dict[str, float]      # Without skill
    impact_metrics: Dict[str, float]        # With skill
    deltas: Dict[str, float]                # Improvement
    effectiveness_score: float              # 0-10
    
    # Metadata
    judge_type: str                         # "vertex-ai" | "anthropic" | "openai"
    dataset_size: int                       # Number of samples
    execution_time_ms: float                # How long it took
    errors: List[str]                       # Any errors encountered
```

### EvaluationDataset

```python
@dataclass
class EvaluationDataset:
    id: str                                 # e.g., "qa-dataset"
    name: str                               # e.g., "Customer QA"
    description: str                        # What it's for
    samples: List[EvaluationSample]         # Test cases
    created: datetime                       # When created
    updated: datetime                       # Last modified
    tags: List[str]                         # e.g., ["qa", "customer-support"]
    metadata: Dict[str, Any]                # Custom data
```

### EvaluationSample

```python
@dataclass
class EvaluationSample:
    input: str                              # User input
    expected_output: str                    # Expected response
    sample_id: Optional[str]                # Unique ID
    tags: List[str]                         # e.g., ["edge-case", "critical"]
    metadata: Dict[str, Any]                # Custom data
```

## Common Workflows

### Workflow 1: Evaluate a New Agent-Generated Skill

```bash
# 1. Generate the skill
keel skill generate --path ./my-project

# 2. Create evaluation dataset (if needed)
keel eval dataset create my-dataset --description "Test cases"

# 3. Validate the skill
keel eval validate skill .skills/my-skill/SKILL.md

# 4. Run evaluation
keel eval run skill \
  --agent my-agent \
  --skill my-skill \
  --dataset my-dataset \
  --judge anthropic

# 5. Check results
keel eval report list
```

### Workflow 2: Evaluate All Installed Skills

```bash
# 1. Create evaluation dataset
keel eval dataset create comprehensive-test --description "Full test suite"

# 2. Evaluate all skills (Phase 2)
keel eval run all-skills \
  --dataset comprehensive-test \
  --agent my-agent \
  --parallel 4

# 3. Compare results (Phase 4)
keel eval compare skills \
  --skills "all" \
  --dataset comprehensive-test \
  --agent my-agent

# 4. View trends (Phase 6)
keel eval report trends --period "30d"
```

### Workflow 3: Certify a High-Quality Skill

```bash
# 1. Run evaluation
keel eval run skill \
  --agent my-agent \
  --skill my-skill \
  --dataset my-dataset

# 2. Check quality score (from results)
# Quality Score: 85/100

# 3. Certify the skill (Phase 5)
keel eval certify skill \
  --skill my-skill \
  --level CERTIFIED \
  --reason "Meets all quality requirements"

# 4. Verify certification
keel eval show certification my-skill
```

### Workflow 4: Compare Two Skills

```bash
# 1. Create dataset
keel eval dataset create comparison-test

# 2. Compare skills (Phase 4)
keel eval compare skills \
  --skills "skill-a,skill-b" \
  --dataset comparison-test \
  --agent my-agent \
  --metrics "accuracy,helpfulness,latency_ms"

# 3. View comparison report
# Shows ranking, metric comparison, recommendations
```

## Troubleshooting

### Issue: Skill Validation Fails

**Symptoms**: `eva eval validate skill` returns errors

**Solutions**:
1. Check YAML frontmatter syntax
2. Verify required sections present (Instructions, Available Tools, Workflow)
3. Check Markdown formatting
4. Ensure UTF-8 encoding

**Command to debug**:
```bash
keel eval validate skill <path> --output json
```

---

### Issue: Evaluation Takes Too Long

**Symptoms**: `keel eval run skill` runs for hours

**Solutions**:
1. Reduce dataset size (use fewer samples)
2. Use faster judge (anthropic vs vertex-ai)
3. Reduce metrics (evaluate only critical ones)
4. Use parallel processing (Phase 2)

**Optimization**:
```bash
# Use smaller dataset
keel eval run skill \
  --agent my-agent \
  --skill my-skill \
  --dataset small-test \
  --metrics "accuracy,helpfulness"
```

---

### Issue: LLM Judge API Fails

**Symptoms**: `Generation failed: API error` or `Judge not available`

**Solutions**:
1. Check API credentials (ANTHROPIC_API_KEY, GOOGLE_APPLICATION_CREDENTIALS)
2. Verify API quota and rate limits
3. Try fallback judge (anthropic → openai)
4. Check network connectivity

**Debug**:
```bash
# Check available judges
keel eval metrics list

# Try different judge
keel eval run skill \
  --agent my-agent \
  --skill my-skill \
  --dataset my-dataset \
  --judge openai
```

---

### Issue: Dataset Not Found

**Symptoms**: `Dataset not found: my-dataset`

**Solutions**:
1. Create the dataset first
2. Check dataset ID spelling
3. List available datasets

**Fix**:
```bash
# List datasets
keel eval dataset list

# Create if missing
keel eval dataset create my-dataset --description "..."
```

---

### Issue: Skill Not Found

**Symptoms**: `Skill not found: my-skill`

**Solutions**:
1. Install or generate the skill first
2. Check skill name spelling
3. List installed skills

**Fix**:
```bash
# List skills
keel skill list

# Install if missing
keel skill install <source>

# Or generate
keel skill generate
```
